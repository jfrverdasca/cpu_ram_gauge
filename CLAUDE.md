# Project rules

## Commits and pull requests
- Never add a `Co-Authored-By: Claude ...` trailer to commits, nor any Claude
  attribution (e.g. "Generated with Claude Code") to pull request descriptions.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages:
  `<type>(<optional scope>): <description>`, e.g. `fix(lcd): even scroll steps`.
  Types: `feat`, `fix`, `docs`, `test`, `refactor`, `perf`, `build`, `chore`.
  Scopes, when useful: `firmware`, `pc`, `lcd`, `email`, `docs`, `tests`.
